# Kimai Tray (nazwa robocza)

Aplikacja na Linuksa w **tacce systemowej** do mierzenia czasu w **Kimai** — start/stop
timera, ostatnie wpisy, wznawianie, billable, sumy dnia i tygodnia. Dystrybuowana jako
**Flatpak**, działa w KDE Plasma i GNOME (z rozszerzeniem AppIndicator).

Natywny odpowiednik wtyczki przeglądarkowej
[WS Tracker](https://github.com/websystemspl/kimai-ws-tracker).

![Wzorzec UI — wtyczka WS Tracker](docs/assets/referencja/popup-trwa.png)

> **Status:** w budowie — działa aplikacja w tacce na KDE (okno przy tacce, ustawienia, powiadomienia, autostart);
> paczka Flatpak w przygotowaniu.
