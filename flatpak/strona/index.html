Czas pracy w Kimai
w natywnej aplikacji Your Kimai hours
in a native desktop app

Wpisy z całego tygodnia, podsumowania ze średnią i normą dzienną oraz kalendarz, w którym wpis przesuwasz myszą — w jednym oknie, bez karty w przeglądarce. A timer zostaje pod ręką: ikona w tacce pokazuje, ile trwa bieżący wpis. A week of entries, summaries with a daily average and norm, and a calendar where an entry moves with the mouse — in one window, without a browser tab. The timer stays at hand: the tray icon shows how long the current entry runs.

WidokiViews

Trzy spojrzenia na ten sam czas pracy Three ways to look at the same working time

WpisyEntries

Tydzień po tygodniu, z sumą każdego dnia. Kliknięcie wpisu otwiera okno edycji ze wszystkim, co pozwala zmienić Twój serwer — godziny, projekt, tagi, pola własne. Czas wpiszesz też ręcznie, a usunięty wpis przez chwilę da się cofnąć. Week by week, with each day's total. A click on an entry opens an edit window with all your server lets you change — hours, project, tags, custom fields. Time can be typed in by hand, and a deleted entry can be brought back for a moment.

PodsumowaniaSummaries

Tydzień, miesiąc, rok albo dowolny zakres: ile czasu, ile z tego płatnego i ile średnio na dzień roboczy wobec normy. Wykres dni w kolorach projektów i podział wg projektu, klienta lub rodzaju pracy — po najechaniu widać wpisy, które się na to składają. A week, a month, a year or any range: how much time, how much of it billable and the average per working day against your norm. A chart of days in project colours and a breakdown by project, customer or activity — hover to see the entries behind it.

KalendarzCalendar

Dzień albo tydzień, wpisy jako bloki. Przeciągnij w pustym miejscu, żeby dodać wpis; przeciągnij blok, żeby przenieść go na inną godzinę lub dzień, a krawędź — żeby zmienić jego długość. Wszystko przyciąga się do kwadransów. A day or a week, entries as blocks. Drag on an empty spot to add an entry; drag a block to move it to another hour or day, or its edge to change how long it lasts. Everything snaps to quarter hours.

FunkcjeFeatures

A do tego wszystko, co robiła wtyczka WS Tracker Plus everything the WS Tracker extension did

  • Timer zawsze widocznyA timer always in sight

    Ikona w tacce pokazuje czas trwającego wpisu (47m, 1:22); jej menu zatrzymuje, wznawia ostatni wpis i otwiera okno. The tray icon shows how long the running entry lasts (47m, 1:22); its menu stops, resumes the last entry and opens the window.

  • Szybkie okienkoQuick window

    Kliknięcie ikony: opis, projekt, rodzaj pracy i start — albo wznowienie jednego z ostatnich wpisów — bez otwierania całej aplikacji. One click on the icon: description, project, activity and start — or resume one of the recent entries — without opening the whole app.

  • Zasady jak w firmieYour team's rules

    Te same reguły co wtyczka WS Tracker: sprawdzenie jakości opisu, płatne i niepłatne tak, jak ustawiono je w Kimai. The same rules as the WS Tracker extension: a check of the description, billable or not as set up in Kimai.

  • PrzypomnieniaReminders

    Powiadomienie o timerze, który trwa podejrzanie długo, i o utracie połączenia z Kimai. A notification when a timer runs suspiciously long or the connection to Kimai is lost.

  • Z tacką lub bezWith a tray or without

    Na KDE Plasma okienko wyskakuje przy ikonie. Na pulpicie bez tacki wszystko zostaje w oknie głównym — tackę można też po prostu wyłączyć. On KDE Plasma the quick window pops up by the icon. On a desktop without a tray everything stays in the main window — the tray can also simply be turned off.

  • Prywatnie i bezpieczniePrivate and safe

    Token API w portfelu systemu (KWallet / GNOME Keyring). Łączy się wyłącznie z Twoim Kimai — bez telemetrii. The API token lives in the system wallet (KWallet / GNOME Keyring). Talks only to your Kimai — no telemetry.

InstalacjaInstall

Jedna komenda, aktualizacje sameOne command, automatic updates

  1. Z terminalaFrom a terminal

    Dodaje repozytorium DK Tracker i instaluje aplikację. Środowisko KDE pobiera się z Flathuba. Adds the DK Tracker repository and installs the app. The KDE runtime comes from Flathub.

    flatpak install --user {{url}}/io.github.dragonking026.DK-Tracker-Linux.flatpakref

  2. Z centrum oprogramowaniaFrom a software center

    Pobierz plik .flatpakref i otwórz go — Discover albo GNOME Software zaproponuje instalację. Download the .flatpakref file and open it — Discover or GNOME Software offers to install.

  3. Samo źródło aktualizacjiJust the update source

    Plik dk-tracker.flatpakrepo dodaje repozytorium bez instalowania aplikacji. The dk-tracker.flatpakrepo file adds the repository without installing the app.

GNOME: okno główne działa od razu; ikona w tacce pojawi się z rozszerzeniem AppIndicator and KStatusNotifierItem Support. GNOME: the main window works right away; the tray icon appears with the AppIndicator and KStatusNotifierItem Support extension.

Plik .flatpak z wydań na GitHubie też działa, ale tak zainstalowana aplikacja nie dostaje aktualizacji. The .flatpak file from the GitHub releases works too, but an app installed that way gets no updates.

KonfiguracjaSetup

Trzy kroki do pierwszego wpisuThree steps to your first entry

  1. Uruchom z menu programówStart it from the app menu

    Za pierwszym razem okno otworzy się na ustawieniach. The first time, the window opens on the settings.

  2. Podaj adres i token APIEnter the address and API token

    Token utworzysz w Kimai: Profil → API. To nie jest hasło do logowania. Create the token in Kimai: Profile → API. It is not your login password.

  3. Sprawdź i zapiszCheck and save

    Sprawdź połączenie, potem Zapisz — okno przejdzie do Twoich wpisów. Test the connection, then Save — the window moves on to your entries.
