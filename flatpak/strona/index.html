Czas w Kimai
prosto z tacki systemowej Kimai time tracking
right from the system tray

Start, stop i wznawianie pomiaru czasu bez otwierania przeglądarki. Ikona w tacce pokazuje, jak długo trwa wpis — natywna, linuksowa wersja wtyczki WS Tracker dla KDE Plasma i GNOME. Start, stop and resume Kimai timesheets without opening the browser. The tray icon shows how long the timer runs — a native Linux take on the WS Tracker browser extension, for KDE Plasma and GNOME.

FunkcjeFeatures

Wszystko, czego potrzeba do mierzenia czasu — bez karty w przeglądarce Everything you need to track time — without a browser tab

  • Timer w tacceTimer in the tray

    Ikona pokazuje czas trwającego wpisu (47m, 1:22). Z menu: zatrzymaj, wznów ostatni, ustawienia. The icon shows how long the running entry lasts (47m, 1:22). Its menu stops, resumes the last entry or opens the settings.

  • Szybkie oknoQuick window

    Opis, projekt z wyszukiwaniem, rodzaj pracy, płatne / niepłatne i godziny „od / do” — jedno kliknięcie w ikonę. Description, searchable project, activity, billable or not and “from / to” hours — one click on the icon.

  • Wznawianie jednym kliknięciemOne-click resume

    Ostatnie wpisy pogrupowane po dniach, z sumami dnia i tygodnia. Wyszukiwanie we wszystkich swoich wpisach w Kimai. Recent entries grouped by day, with daily and weekly totals. Search across all your entries in Kimai.

  • Okno główneMain window

    Wpisy tygodniami i dniami, edycja każdego pola (tagi, stawki, pola własne), dodawanie ręczne i usuwanie z cofnięciem. Entries by week and day, editing of every field (tags, rates, custom fields), entries added by hand and deleted with undo.

  • PrzypomnieniaReminders

    Powiadomienie o timerze, który trwa podejrzanie długo, i o utracie połączenia z Kimai. A notification when a timer runs suspiciously long or the connection to Kimai is lost.

  • Prywatnie i bezpieczniePrivate and safe

    Token API w portfelu systemu (KWallet / GNOME Keyring). Łączy się wyłącznie z Twoim Kimai — bez telemetrii. The API token lives in the system wallet (KWallet / GNOME Keyring). Talks only to your Kimai — no telemetry.

InstalacjaInstall

Jedna komenda, aktualizacje sameOne command, automatic updates

  1. Z terminalaFrom a terminal

    Dodaje repozytorium DK Tracker i instaluje aplikację. Środowisko KDE pobiera się z Flathuba. Adds the DK Tracker repository and installs the app. The KDE runtime comes from Flathub.

    flatpak install --user {{url}}/io.github.dragonking026.DK-Tracker-Linux.flatpakref

  2. Z centrum oprogramowaniaFrom a software center

    Pobierz plik .flatpakref i otwórz go — Discover albo GNOME Software zaproponuje instalację. Download the .flatpakref file and open it — Discover or GNOME Software offers to install.

  3. Samo źródło aktualizacjiJust the update source

    Plik dk-tracker.flatpakrepo dodaje repozytorium bez instalowania aplikacji. The dk-tracker.flatpakrepo file adds the repository without installing the app.

GNOME: ikona w tacce wymaga rozszerzenia AppIndicator and KStatusNotifierItem Support. Bez niego DK Tracker działa jako zwykłe okno. GNOME: the tray icon needs the AppIndicator and KStatusNotifierItem Support extension. Without it DK Tracker works as a regular window.

Plik .flatpak z wydań na GitHubie też działa, ale tak zainstalowana aplikacja nie dostaje aktualizacji. The .flatpak file from the GitHub releases works too, but an app installed that way gets no updates.

KonfiguracjaSetup

Trzy kroki do pierwszego wpisuThree steps to your first entry

  1. Otwórz ustawieniaOpen the settings

    Kliknij ikonę w tacce → Otwórz ustawienia. Click the tray icon → Open settings.

  2. Podaj adres i token APIEnter the address and API token

    Token utworzysz w Kimai: Profil → API. To nie jest hasło do logowania. Create the token in Kimai: Profile → API. It is not your login password.

  3. Sprawdź i zapiszCheck and save

    Sprawdź połączenie, potem Zapisz — gotowe. Test the connection, then Save — done.
